A one-line loading-screen tip for the make.fun "Loading Screen Gold: A Tip in 200 Characters" bounty. The entry writes a single tip — aimed at a stressed developer watching a build, and at the AI coding agent doing the building — to the harness output file.

The tip: your agent isn't frozen, it's reading the error you skipped. Grab coffee, check the logs, and let it finish before you hit restart.

## Run it

```sh
python3 main.py
```

It writes one line (137 characters) to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set.
